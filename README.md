# سرزمین خوابالوها

یک مینی‌سایت فارسی، راست‌چین و کاملاً استاتیک برای نمایش روی موبایل. هیچ وابستگیِ ساخت، فریم‌ورک، یا کلید API ندارد.

## پیش‌نمایش محلی

ساده‌ترین راه این است که فایل `index.html` را در مرورگر باز کنید. برای تجربهٔ نزدیک‌تر به انتشار، در همین پوشه یک وب‌سرور محلی اجرا کنید؛ مثلاً با افزونهٔ Live Server در VS Code یا هر سرویس‌دهندهٔ استاتیک دیگر.

## شخصی‌سازی

نام عمومی فعلی در ابتدای فایل `script.js` قرار دارد:

```js
const personalName = "خوابالوی دوست‌داشتنی";
```

آن را با اسم یا لقب دلخواه جایگزین کنید. متن نامه نیز در `index.html`، داخل بخش `love-note` قابل ویرایش است.

## انتشار

کل پوشه را بدون تغییر روی هر میزبان فایل استاتیک منتشر کنید، مانند GitHub Pages، Netlify، Vercel یا Cloudflare Pages. فایل ورودی سایت `index.html` است و تنظیم build لازم نیست.

## ساختار

- `index.html` — ساختار، محتوای فارسی و عناصر تزئینی
- `styles.css` — طراحی موبایل‌محور، RTL و انیمیشن‌ها
- `script.js` — آزمون، صفحهٔ نتیجه، اتاق، نامه و حالت خواب
